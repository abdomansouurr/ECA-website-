# ♟️ Egypt Chess Academy (ECA) — Training Curriculum Portal

An interactive, fast, and responsive web portal designed for **Egypt Chess Academy (ECA)** coaches to easily access, search, and share **Lichess** training studies, examples, and exercises across structured curriculum steps.

## ✨ Features
- **👑 Luxury Black & Gold Theme:** Eye-friendly dark mode with subtle animated chess background particles (plus Light Mode support).
- **📂 Expandable Step Lists:** Organized vertical accordion lists for Steps 1–6.
- **⚡ Instant Search:** Real-time filtering across all steps and lesson titles (supports `/` keyboard shortcut).
- **🔗 One-Click Lichess Access & Copy:** Direct clickable lesson titles, categorized badges (`Examples` & `Exercises`), and instant clipboard copy buttons for sharing homework with students.

## 🚀 Usage
Simply open `index.html` in any browser or visit the live deployment link.

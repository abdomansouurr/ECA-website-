# vendor/ — المكتبات الخارجية (بدل الـ CDN)

الموقع بيحمّل المكتبتين دول من هنا بس (مفيش CDN). لو الملفات اتمسحت اللعب ضد الكمبيوتر والألغاز هتقف:

| الملف | المكتبة | الترخيص |
|---|---|---|
| `chess.js` | chess.js 1.0.0 (منطق الشطرنج) | BSD-2 |
| `stockfish.js` | Stockfish.js 10.0.2 (المحرك) | GPLv3 — لازم تفضل ملاحظة الترخيص والمصدر ظاهرة |

## التحميل (مرة واحدة، محتاج إنترنت و Node 18+)
```
npm run vendor
```
بيطبع SHA-256 لكل ملف. بعد كده commit للملفين (`vendor/chess.js` و `vendor/stockfish.js`) وارفع.
